# Standardization Radar Chart — A8.6

- Creator / Publisher / Viewer with a common engine, explicit selection of radars and published revisions.
- Standalone radar-centric Viewer, single radar or collection, ISO references and details.
- Verified ZIP deliveries, manifest, SHA-256, software provenance and delivery history.
- Configuration comparison, duplicate generation confirmation, optional reason and JSON persistence.
- Single standalone HTML candidate consultation action; no delivery recorded for consultation.

Open the standalone HTML files locally in a browser. The Creator includes the ISO catalogue; the Viewer does not include the global ISO corpus. The legacy PLM and independent Client remain available on GitHub Pages. Workspace-level binary archiving and download-free standalone preview are deferred. The catalogue stores delivery records, not the historical ZIP bytes.
