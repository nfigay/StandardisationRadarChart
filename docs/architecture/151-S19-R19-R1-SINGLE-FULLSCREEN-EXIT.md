# S19-R19-R1 — Commande unique de sortie du plein écran

Le document plein écran R19 est hébergé dans un layout W2UI racine et conserve le nœud vivant Tiptap.

## Contrat ergonomique
- Mode compact : une commande « Pleine page » dans l’en-tête du dossier.
- Mode plein écran : cette commande est masquée ; **seul** le bouton « Réduire » dans l’en-tête du layout reste visible.
- Échap referme également le mode plein écran au clavier.
- À la fermeture, le bouton « Pleine page » réapparaît dans le panneau droit.

Cette correction n’ajoute aucune instance d’éditeur, aucune écriture documentaire ni aucun changement de géométrie radar.
